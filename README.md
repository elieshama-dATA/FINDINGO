# FINDINGO — Front-end V2

Prototype complet HTML, CSS et JavaScript natif, sans backend.

## Lancement
Ouvrir `index.html` avec VS Code et Live Server.

## Pages
Accueil, recherche visuelle, résultats, fiche produit, boutiques, détail boutique, favoris, connexion, inscription, tableau de bord, ajout produit, mes produits et profil boutique.

## Interactions locales
Favoris, filtres, tri, importation et aperçu d'image, ajout/suppression de produits et sauvegarde du profil via LocalStorage. Les formulaires de compte affichent un message de démonstration.

## Limites
Aucun compte réel, paiement, contact vendeur connecté, statistique réelle ou moteur IA. Données fictives et stockage local au navigateur. Images distantes nécessitent Internet.
